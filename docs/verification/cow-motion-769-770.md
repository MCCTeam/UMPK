## Runtime decisions

| Area | Implemented behavior | Limits |
|---|---|---|
| Identity and ownership | EntityApplier registers a Cow family profile with the existing motion, membership and geometry owners before spawn publication. It does not register a player or add a timer. | Only Cow on 769/770. |
| Relative/partial packets | 769 uses the original inline three-step interpolation and pending missing components; 770 uses the existing offset-box controller and current missing components. Packet-coordinate bases remain separate. | Unsupported teleport variants become unknown. |
| Position sync | Native near updates interpolate; unloaded/far updates snap while retaining the existing pending target. Every target/query phase is retained. | No invented reset of the packet target. |
| Velocity and travel | Packet velocity applies immediately. On an inactive interpolation phase it is multiplied by .98, then each component with absolute value below .003 is zeroed. Exactly .003 survives an active phase. Dry remote Cow ticks do not invent local travel/gravity. | Fluid, powered block/body interactions and local travel authority outside the measured branch remain unknown. |
| Eligibility | Actual received full-column membership, column unload/reload/crossing and the existing world freeze/exact-step owner gate Cow ticks. Block writes alone cannot establish native terrain. Query visibility stays independent from tick eligibility. | No universal player radius gate and no Physics-feature gate. |
| Collision | The actual Cow source uses existing exact block grids, border and hard-entity predicates for 770's controller. A Cow is nonhard; a known alive Shulker is hard; unknown eligible hard peers stay unknown. | Placement, picking, pushability and canCollideWith remain distinct. Boat trajectories are not proven. |
| Local push relevance | Prefer the current physics owner's body. When physics is disabled, a native float envelope over the existing eighteen player pose dimensions and owned scale can prove only nonintersection. It never becomes the actual body or a push trajectory. Missing position/profile/scale, mount/camera ambiguity or ignored self pose/bed state remains unknown. | No second self actor or guessed standing box. |
| Shulker expansion | A conservative all-face influence bound may prove a known Shulker is irrelevant. An unowned or intersecting expansion source makes Cow motion unknown. | 769's unowned Shulker bounds remain unknown even in the far-sync control. No Shulker push implementation is claimed. |
| Invalid contexts and lifetime | Baby/pose/scale/equipment/health/shared-flag changes outside the bounded profile, mounts/riders, fluids, death callbacks and missing collision decisions invalidate moving bounds. Removal, ID replacement, world replacement and session teardown release existing ownership; same-world respawn retains the peer and its pending interpolation. | Once Cow motion becomes unknown, this slice conservatively keeps it unknown until actor replacement. |

The source-aware collision adapter is still internally named ModernPlayerCollision; its existing controller arithmetic and world queries are reused with an explicitly registered Cow source. This does not reuse RemotePlayer velocity, authority, noPhysics or identity semantics.
