# Code of Conduct

UMPK should be a place where people can discuss difficult technical work without mistreating each other. Be direct about code. Be considerate with people.

## Expected behavior

- Treat other contributors with respect.
- Give useful, specific feedback.
- Accept correction and update your work when evidence changes.
- Respect privacy, credentials, and private server information.
- Keep disagreements focused on the project and its technical evidence.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Sexual attention or imagery that another person does not welcome.
- Publishing private information without permission.
- Repeated disruption, spam, or bad-faith participation.
- Retaliation against a person who reports a problem.

## Scope

This code applies in the repository, project discussions, reviews, and other spaces where someone represents UMPK.

## Reporting

Report conduct problems privately to a project maintainer. Use the private contact details on the maintainer's GitHub profile. Do not post sensitive details in a public issue.

Maintainers will review reports, protect privacy where possible, and choose a response that fits the situation. Responses can include a warning, content removal, a temporary restriction, or a permanent ban. A maintainer named in a report must not decide its outcome alone.
