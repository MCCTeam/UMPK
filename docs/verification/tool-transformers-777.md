## Height boundary

Original `Level.getBlockState` lines 353–359 returns `VOID_AIR` outside the dimension height, and `StateTestingPredicate` line 23 applies the offset before that lookup. UMPK storage returns state-zero air beyond the column height. Four actual-session packet cases put the clicked soil at `MaxY - 1` and supply custom AIR tags that distinguish ordinary air from void air. The original candidate gives the wrong known result in all four. The corrected helper resolves the registered `void_air` default state for the known out-of-height probe, then queries the received tag; a missing definition remains unknown. This change does not copy the unrelated ±30-million spawn/world predicate or claim wider horizontal context.
