## Equipment and underwater progress

Before the submerged-mining-speed attribute, native Aqua Affinity checks all four armor slots, including enchantments that a server puts on another armor slot. UMPK now scans slots 5 through 8; an unequipped item remains a negative control. Attribute detection also recognizes the `player.` names used by protocol 767, so a wire-populated mining-efficiency attribute affects the scheduled action across the later rename.
