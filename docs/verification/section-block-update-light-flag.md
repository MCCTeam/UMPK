# Preserve the native section-update light flag

UMPK discarded the native `suppressLightUpdates` Boolean from section block updates in protocols 751–762 and encoded it as false. A real 1.17 slab acceptance run reached all 11 expected action outcomes, then failed its byte-identical capture replay because native payload byte 8 was 1 and UMPK wrote 0. The native row remains failed; its separate persisted-world settings gate also failed.

## Scope and source evidence

The fix preserves this existing field through the existing `SectionBlocksUpdateV1_16_2` codec. It adds `ClientboundSectionBlocksUpdatePacket.SuppressLightUpdates { get; init; }`, default false, and the corresponding public API entries. The five-parameter primary constructor, deconstruction, packet registration and codec timeline remain unchanged. No dataset, feature, dependency, package version or pin changes are required.

`native-source-audit.json` binds source hashes, completion receipts, official artifact receipts and server JAR hashes for 14 affected named releases covering 11 protocol datasets: 1.16.2/751, 1.16.3/753, 1.16.4 and 1.16.5/754, 1.17/755, 1.17.1/756, 1.18 and 1.18.1/757, 1.18.2/758, 1.19/759, 1.19.1 and 1.19.2/760, 1.19.3/761, and 1.19.4/762. Each original native packet reads and writes the Boolean between the packed section position and change count. The adjacent native controls 1.20 and 1.20.1/763 omit it. Protocol 736 is an additional legacy unit-shape control, not another source-audited release.

The exact native witness is frame 287 at 691.3859 ms, clientbound protocol 755 packet ID 63, from `modern-slab-native-flat-c849-20261024-v3/legs/3-755/evidence/1.17-f0f0b0fdb88c423aa788bae2217f2f88`. Its 172-byte payload has SHA-256 `7491acd53b78df6f3e1ce0781bd0b5644caa6847c8adb1ab994fee10ef7382e7`, section position -30786319286266, a true flag, and 81 ordered state-1 changes. `native755-frame.json` contains every decoded position/state and hashes the source capture and failing TRX. The false test variant changes only the native flag byte; it is a derived control, not claimed as a second native capture.
